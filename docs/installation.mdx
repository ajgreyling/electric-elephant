## npm

<Tabs>
  <Tab title="npx">
    ```bash
    # PostgreSQL example
    npx electric-elephant \
      --transport http \
      --port 8080 \
      --dsn "postgres://user:password@localhost:5432/dbname?sslmode=disable"
    ```
  </Tab>

  <Tab title="Global Installation">
    ```bash
    # Install globally
    npm install -g electric-elephant

    # Run the server
    electric-elephant --transport http --port 8080 --dsn "postgres://..."
    ```
  </Tab>
</Tabs>

## Docker

<Tabs>
  <Tab title="Docker Run">
    ```bash
    docker run --rm --init \
      --name electric-elephant \
      --publish 8080:8080 \
      electric-elephant \
      --transport http \
      --port 8080 \
      --dsn "postgres://user:password@localhost:5432/dbname?sslmode=disable"
    ```

    <Warning>
    When connecting to databases on your host machine from Docker, use `host.docker.internal` instead of `localhost`:

    ```bash
    --dsn "postgres://user:password@host.docker.internal:5432/dbname"
    ```
    </Warning>
  </Tab>

  <Tab title="Docker Compose">
    For development environments using Docker Compose, add Electric Elephant to your `docker-compose.yml`:

    ```yaml docker-compose.yml
    services:
      electric-elephant:
        image: electric-elephant:latest
        container_name: electric-elephant
        ports:
          - "8080:8080"
        command:
          - --transport
          - http
          - --port
          - "8080"
          - --dsn
          - "postgres://user:password@database:5432/dbname"
        depends_on:
          - database

      database:
        image: postgres:15-alpine
        environment:
          POSTGRES_PASSWORD: password
          POSTGRES_DB: dbname
    ```
  </Tab>
</Tabs>

## Client Integration

Once Electric Elephant is installed and running, configure your MCP client to connect to it.

### Claude Code

<Tabs>
  <Tab title="CLI">
    <Tabs>
      <Tab title="Stdio">
      For local database connections, use stdio transport:

      ```bash
      claude mcp add --transport stdio electric-elephant -- npx electric-elephant --transport stdio --dsn "postgres://user:password@localhost:5432/dbname"
      ```

      <Note>
      The `--` separates Claude's flags from Electric Elephant's arguments. Everything after `--` is the Electric Elephant command.
      </Note>
      </Tab>
      <Tab title="HTTP">
      For remote or shared database servers, use HTTP transport:

      ```bash
      claude mcp add --transport http electric-elephant http://localhost:8080/mcp
      ```

      This connects to a Electric Elephant server running with HTTP transport:

      ```bash
      npx electric-elephant --transport http --port 8080 --dsn "postgres://user:password@localhost:5432/dbname"
      ```
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="Project Configuration">
    For project-specific database connections shared with your team, create `.mcp.json` in your project root.

    <Tabs>
      <Tab title="Stdio">
      ```json .mcp.json
      {
        "mcpServers": {
          "electric-elephant": {
            "type": "stdio",
            "command": "npx",
            "args": [
              "electric-elephant",
              "--transport",
              "stdio",
              "--dsn",
              "postgres://user:password@localhost:5432/dbname"
            ]
          }
        }
      }
      ```

      <Tip>
      Use environment variable expansion for sensitive values:
      ```json .mcp.json
      {
        "mcpServers": {
          "electric-elephant": {
            "type": "stdio",
            "command": "npx",
            "args": [
              "electric-elephant",
              "--transport",
              "stdio",
              "--dsn",
              "${DATABASE_URL}"
            ]
          }
        }
      }
      ```
      </Tip>
      </Tab>
      <Tab title="HTTP">
      ```json .mcp.json
      {
        "mcpServers": {
          "electric-elephant": {
            "type": "http",
            "url": "http://localhost:8080/mcp"
          }
        }
      }
      ```
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="User Configuration">
    For personal configuration across all projects:

    ```bash
    claude mcp add --scope user electric-elephant -- npx electric-elephant --transport stdio --dsn "postgres://user:password@localhost:5432/dbname"
    ```

    Or manually edit the user configuration file:

    <Tabs>
      <Tab title="MacOS/Linux">
        Edit `~/.claude/settings.json` and add to the `mcpServers` section.
      </Tab>
      <Tab title="Windows">
        Edit `%USERPROFILE%\.claude\settings.json` and add to the `mcpServers` section.
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

**Using Electric Elephant:**

Start Claude Code in your project directory:

```bash
claude
```

Verify Electric Elephant is loaded:

```bash
/mcp
```

### GitHub Copilot CLI

<Tabs>
  <Tab title="Interactive">
    Use the Copilot CLI to interactively add the MCP server:

    ```
    /mcp add
    ```

    When prompted, you'll need to provide:
    - **Server type**: select `local` (the default)
    - **Server name**: for example, `electric-elephant`
    - **Command**: `npx electric-elephant`
    - **Arguments**: transport (e.g., `--transport stdio`) and a PostgreSQL `--dsn` connection string (or use `--config` with `dbhub.toml`)
  </Tab>

  <Tab title="Config File">

### Dify

Electric Elephant must be running as an HTTP server for Dify to connect. Start Electric Elephant with HTTP transport:

```bash
npx electric-elephant --transport http --port 8080 --dsn "postgres://user:password@localhost:5432/dbname"
```

**Configuration:**

1. In Dify, navigate to **Tools → MCP**
2. Click **Add MCP Server (HTTP)**
3. Configure the server:
   - **Server URL**: `http://localhost:8080/mcp` (or your Electric Elephant host)
   - **Name**: `Electric Elephant`
   - **Server Identifier**: `electric-elephant` (permanent, max 24 characters)

4. Click save. Dify will automatically discover Electric Elephant's tools.

**Using Electric Elephant Tools:**

Once connected, Electric Elephant tools are available in:

- **Agents**: Tools appear alongside built-in tools, use "Add All" to enable all Electric Elephant tools
- **Workflows**: Tools appear as available node types

**Multiple PostgreSQL sources:**

Use TOML configuration:

```bash
npx electric-elephant --transport http --port 8080 --config /path/to/dbhub.toml
```

**Limitations:**
- Dify only supports HTTP transport (not stdio)
- Electric Elephant must be network-accessible from Dify

**References:**
- [Dify MCP Documentation](https://docs.dify.ai/en/guides/tools/mcp)

### LibreChat

Electric Elephant can be integrated with [LibreChat](https://www.librechat.ai/) using either **stdio** or **Streamable HTTP** transport.

<Tabs>
  <Tab title="stdio">
    ```yaml librechat.yaml
    mcpServers:
      electric-elephant:
        type: stdio
        command: npx
        args:
          - -y
          - "electric-elephant"
          - "--dsn"
          - "postgres://user:password@localhost:5432/dbname"
        timeout: 60000
    ```

  </Tab>

  <Tab title="Streamable HTTP">
    ```yaml librechat.yaml
    mcpServers:
      electric-elephant:
        type: streamable-http
        url: http://host.docker.internal:8080/mcp
        timeout: 60000
    ```

    <Note>
      **Docker Networking:** When LibreChat runs in Docker (e.g., with docker-compose), use `host.docker.internal:8080` to connect to Electric Elephant running on your host machine. This is Docker's special DNS name that resolves to the host's IP address.

      For native installations, use `http://localhost:8080/mcp` instead.
    </Note>
  </Tab>
</Tabs>

**References:**
- [LibreChat MCP Documentation](https://www.librechat.ai/docs/configuration/librechat_yaml/object_structure/mcp_servers)
