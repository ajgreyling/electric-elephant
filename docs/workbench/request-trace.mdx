The Request Trace page (`/requests`) in Electric Elephant displays recent tool executions, helping you track queries and debug issues.

![request-trace](https://raw.githubusercontent.com/bytebase/dbhub/main/docs/images/workbench/request-trace.webp)

## Data Retention

Request traces are stored in memory (resets on restart), keeping the latest 100 requests per source.

## Literal redaction

The SQL text shown in request traces (and returned by the `/api/requests` endpoint) is **redacted**: string and numeric literals are replaced with `?` placeholders (e.g. `WHERE email = 'bob@x.com'` becomes `WHERE email = '?'`), and comments are removed. This preserves the query shape for debugging while preventing personal data embedded in literals from being retained or exposed. Column and table names are preserved.
